Individual location notes go in this folder using [[Location]] from the templates.

### A run is one location

- The player picks a location from a menu and plays it until they win or lose.
- Winning unlocks the next location and returns the player to the menu. It does not push them straight into it.
- This follows Frostpunk 1. It is not the chained biome model used by Hades or Megabonk.

### Structure of a location

- The premise of a location is fixed.
- Terrain layout is randomized per run.
- Raids escalate to a boss.

### Open

- **Open:** How many locations at launch.
- **Open:** Target length of a single run. This constrains raid count and economy depth, so it blocks a lot of tuning.
- **Proposal:** Each location needs its own twist, not just a higher difficulty number. With one location per run, a set of locations that only differ in difficulty means everyone plays the newest one and the earlier ones die. Frostpunk gave each scenario its own rules and its own goal. Examples of the shape, scarce resources with a wide ring, or raids at double frequency and half length.
