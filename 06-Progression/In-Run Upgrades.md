### Summary

Upgrades earned and spent inside a single run. Lost when the run ends.

### What is known

- The hero buff is the largest in run modifier and defines the build. See [[Units]].
- Unit tiers unlocking through a run is progression in its own right. See [[Units]].

### Open

- **Open:** Whether there is a separate in run upgrade currency at all, or whether resources and tiers cover it.
- **Open:** Where upgrades come from. Raid rewards, structures, map events, or choices on level up.
- **Open:** How often the player gets one.
- **Open:** Whether upgrades are offered as a choice of several, which is the standard roguelite pattern.
