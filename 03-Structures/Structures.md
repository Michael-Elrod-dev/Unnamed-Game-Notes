Individual structure notes go in this folder, one per structure, using [[Structure]] from the templates.

### Rules

- Structures are built on tiles inside the city footprint. See [[City & Building]].
- Structures cost resources.
- Enemies target structures during a raid.

### Discussed so far

These came up in conversation as examples of the kind of thing that exists. None are confirmed and the list is not final.

- A defense tower or watchtower, covering one approach so troops can cover another.
- A barracks for training units.
