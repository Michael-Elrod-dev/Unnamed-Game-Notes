Single player turn based roguelite. You hold a fixed city on a hex map against escalating raids, building an economy and an army in the gaps between attacks.

### Shape

- Hex grid map. Terrain and tile interaction modeled on Civ 6. See [[Map & Terrain]].
- Map is roughly one continent. Slightly larger than the camera view, and not a world map.
- Starting position is auto placed.
- Terrain is randomized per run inside a fixed premise per location.
- One run is one location. See [[Locations]].
- Losing ends the run and the city is gone. Only meta currency survives. See [[Meta Progression]].

### Reference points

- **Frostpunk 1** for siege pressure, worker assignment, and knowing when the next event lands.
- **Civ 6** for the hex map, terrain, and turn based combat.
- **Warcraft** for base economy and unit tiers.
- **Hades** for a single choice at the top of a run defining how it plays.
- **Megabonk** and **Vampire Survivors** for currency earned in a run and spent outside it.
- **Clash of Clans** as a rough visual target.

### Setting

Undecided and intentionally open. Every system in this vault works without naming a setting.

Candidates discussed are high fantasy, zombie apocalypse, and a Chernobyl themed run toward increasingly mutated creatures. Choosing across themes is out of scope. Choosing a race inside one theme is in scope. See [[Open Questions]].
